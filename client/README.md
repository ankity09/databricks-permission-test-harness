# Permission Test Harness: frontend

React 19 + TypeScript + Vite + Tailwind. This is the client for the
[Databricks Permission Test Harness](../README.md); FastAPI serves the built
output (`client/dist`) as static files.

## Commands

```bash
npm ci
npm run dev    # Vite dev server with HMR
npm run lint   # oxlint
npm run build  # production build
```

See the [root README](../README.md) for architecture and deployment.
